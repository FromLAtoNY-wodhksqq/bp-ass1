# 사용자 직접 검사 결과 기록표

수행 주체: 사용자. AI가 전달받은 총 19장 중 안전하게 보관한 18장 캡처의 관찰 가능한 범위만 결과표에 옮겼다. 부분 확인은 실패가 아니라 전체 시나리오 조건·응답의 일부만 증거로 확인됐다는 뜻이다. AI 자동 검사 결과는 사용자 결과로 옮기지 않는다.

- 실제 수행 날짜·시간: 2026-10-28 22:33~23:28 KST (파일명·화면 응답 시각 기준)
- 코드 커밋 SHA: 촬영 당시 미확인. 현재 커밋으로 소급하지 않음
- 운영체제·Node/npm·브라우저: macOS·Chrome 화면 확인, 당시 Node/npm 미확인
- 접속 주소: http://127.0.0.1:5173 (개발 화면)

## 추가할 증거만 정리

1. 제공 final·expiry 실제 실행 결과, 최신 4173 빌드·접속 확인.
2. 수정 PUT200. 기존 3번은 GET200이다.
3. Bob의 Alice 글 직접 PUT·DELETE403와 실패 후 재조회. 버튼 숨김 사진은 이미 있음.
4. 무토큰 보호 요청·변조 토큰·작성자 위조·서버 입력400, 실제 서버 재시작, Bob 본인 CRUD 등 현재 사진에 없는 T04·T07~T09·T12·T13·T15·T17 조건.
5. 이미 촬영한 오류는 가능하면 Response의 실제 code를 보충한다. T10은 /me 외 POST·PUT·DELETE 만료 거부도 필요하다. T14는 없는 글 수정·삭제와 잘못된 ID도 따로 확인한다.

같은 테스트의 빠진 응답 정보는 요청·응답 기록이나 제공 검사 로그 등으로 보완할 수 있다. AI 자동 검사 로그는 AI가 수행했다는 표시를 유지하고 사용자 직접 수행 결과로 바꾸지 않는다. 전체 수동 항목의 실제 수행 여부는 사용자 설명과 기록을 함께 확인한다.
